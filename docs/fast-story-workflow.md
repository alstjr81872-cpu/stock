# 파일에서 바로 연재

운영 화면은 **파일 · 기획안 → 10화 시놉시스 → 집필** 순서입니다. 초기에 세계관 백과나 상세 모듈을 모두 채울 필요가 없습니다.

1. **새 작품**에서 TXT·MD·DOCX·PDF를 넣습니다. 파일은 8MB 이하, 추출된 본문은 40,000자 이하입니다. 원본을 보관하며 장르와 제목은 파일에서 분석할 수 있습니다.
2. **파일 분석 · 기획안 만들기**를 누르고 비용에 동의합니다. 주인공과 주요 인물, 장르, 문체, 독자가 기대할 재미, 첫 사건, 반복되는 갈등 동력, 최소한의 세계 규칙을 제안합니다.
3. 기획안 미리보기에서 인물 이름·성격·목적과 다른 항목을 직접 다듬습니다. **이 기획으로 10화 설계**를 누르면 기획안을 저장하고 첫 10화 생성의 비용 확인으로 넘어갑니다. 비용에 동의하기 전 유료 생성을 실행하지 않습니다.
4. 각 회차의 사건·선택·결과, 도입과 보상, 복선 일정을 확인하고 **이 구간 기록**을 누릅니다. 설정은 시놉시스에서 필요해질 때 사실과 도입 회차를 기록합니다.
5. 회차 목표 분량을 정하고 장면을 설계합니다. 필요하면 **자동 전개**로 누락·애매함을 점검하고 보완합니다. 플롯 승인 후 시놉시스와 장면을 바탕으로 집필합니다.
6. 원고를 검토·수정하고 복선의 실제 투척/회수를 확인한 뒤 회차를 확정합니다. 10화씩 집필을 마칠 때 다음 10화 구간을 만들지 묻습니다. [상세 안내](serial-synopsis.md).

기획안 생성 후 바로 원고를 자동 확정하지 않습니다. 기획·시놉시스·플롯·원고를 검토할 수 있고, 유료 요청은 매번 사전 비용을 확인합니다. 자동 유료 재시도는 없습니다.

기존 작품에서도 파일에서 새 기획을 만들 수 있습니다. 기획안 적용은 **새 연재 버전으로 다시 시작**하므로 첫 회차로 돌아갑니다. 기존 기획 전체·시놉시스·원고는 보관하며 프로젝트 내보내기에 포함됩니다. 기존 원고 내용을 자동으로 덮어쓰거나 개작하지 않습니다.

## 재미를 위한 생성 기준

설명과 준비 동작을 오래 보여주고 주인공이 사건에 끌려가기만 하면, 설정이 풍부해도 초반이 밋밋해질 수 있습니다. 생성 지침은 첫 사건·선택·반격·작은 보상을 앞당기고, 지식은 사건을 해결하는 행동으로 드러내도록 바꿨습니다. 장면 분량도 균등 배분하지 않고 충돌과 보상에 더 많은 비중을 줄 수 있습니다.

독립 검토는 긴 설명, 반복된 반응, 주인공의 무기력, 기대한 보상 누락을 구체적인 위치와 함께 지적하도록 합니다. 재미와 문체는 규칙만으로 보장할 수 없으므로 새로 생성한 1화에서 실제 문장과 독서 흐름을 확인하세요. 테스트는 모델 응답 대역을 사용하며 실제 작품의 생성 품질 검증을 대신하지 않습니다.
